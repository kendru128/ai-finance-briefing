🔧 One-time Dropbox Setup (~5 minutes)

  1. Go to dropbox.com/developers/apps/create
  2. Choose Scoped access → App folder → give it any name (e.g. AIFinanceBriefing) → click Create app
  3. Go to the Permissions tab → tick files.content.read and files.content.write → click Submit
  4. Go back to Settings tab → copy the App key and App secret into the fields above
  5. Click "Authorise with Dropbox" → approve in the browser → copy the code back here → click "Connect"

⚠️ Always set permissions before authorising — tokens are stamped with the permissions that exist at authorisation time. To disconnect: click here.
